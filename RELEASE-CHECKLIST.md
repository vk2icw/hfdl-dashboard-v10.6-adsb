# Release Checklist

- [ ] Set the version number.
- [ ] Test from a clean installation directory.
- [ ] Confirm UDP reception and database creation.
- [ ] Confirm all API endpoints return successfully.
- [ ] Confirm alerts and browser notifications.
- [ ] Confirm OpenSky import.
- [ ] Confirm database backup and restore workflow.
- [ ] Confirm About and Legal links.
- [ ] Confirm visible OpenStreetMap attribution.
- [ ] Confirm external aircraft links open in a new tab.
- [ ] Remove real usernames and passwords from `compose.yaml`.
- [ ] Exclude the `data` directory, databases, logs and backups.
- [ ] Include LICENSE, DISCLAIMER, PRIVACY, SECURITY and THIRD_PARTY_NOTICES.
- [ ] Scan the release archive for secrets.
- [ ] Create a checksum for the published archive.
- [ ] Sign the installer when the Windows edition is produced.
